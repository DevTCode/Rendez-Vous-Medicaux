# 🏥 Gestion des rendez-vous médicaux

Application Java de gestion des rendez-vous médicaux permettant aux **patients** et **médecins** de gérer leurs rendez-vous via des interfaces dédiées.

## ✨ Fonctionnalités

- 🔐 Authentification des utilisateurs
- 👨‍⚕️ Tableau de bord médecin
- 👤 Tableau de bord patient
- 📅 Gestion des rendez-vous
- 🗓️ Gestion des disponibilités et plannings
- 💾 Connexion à une base de données

## 🛠️ Technologies

- Java
- JavaFX
- MySQL
- JDBC

## 📁 Structure

Le projet contient notamment :
- `LoginController.java` — authentification
- `DoctorDashboardController.java` — espace médecin
- `PatientDashboardController.java` — espace patient
- `Appointment.java` — gestion des rendez-vous
- `Schedule.java` — gestion des plannings
- `DBconnection.java` — connexion à la base de données

## 🚀 Objectif

Simplifier la gestion des rendez-vous médicaux et faciliter l'interaction entre patients et médecins.
